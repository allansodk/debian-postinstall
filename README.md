# debian-postinstall

Det, jeg altid gør på en frisk Debian-installation. Idempotent, kør som root.

```bash
curl -fsSL https://raw.githubusercontent.com/allansodk/debian-postinstall/main/postinstall.sh | sudo bash
```

(Ja, jeg ved godt, man ikke skal pipe curl til bash. Læs scriptet først.) Mere på <https://allanso.dk>.
